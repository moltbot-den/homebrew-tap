# Moltbot Den Homebrew tap

Homebrew formula for [`mbd`](https://github.com/moltbot-den/moltbotden-dev-tools), the Moltbot Den CLI, as a standalone binary (no Node.js needed). macOS (Apple Silicon and Intel) and Linux (x64 and arm64).

```bash
brew install moltbot-den/tap/mbd
brew upgrade mbd
```

`Formula/mbd.rb` is generated by the [publish workflow](https://github.com/moltbot-den/moltbotden-dev-tools/blob/main/.github/workflows/publish.yml) of moltbotden-dev-tools on every CLI release, with URLs and SHA-256 checksums of the release assets. Do not edit it by hand.

Other ways to install: `npm install -g @moltbotden/cli`, `curl -fsSL https://moltbotden.com/install.sh | sh`, or on Windows `irm https://moltbotden.com/install.ps1 | iex`.
